# Vardhan Steelware Assessment

A product assessment deliverable for a lightweight, phone-first order and outside-polishing tracker.

## Project files

- `Vardhan_Order_Tracker_Prototype.html` — self-contained browser prototype. Open it directly in a modern browser; no installation or server is required.
- `Vardhan_Steelware_Assessment.docx` — assessment write-up covering the proposed requirements, sales handoff, and draft marketing content.

## Product direction

The proposal focuses on making order status, blockers, split dispatches, and outside-polishing lots visible in one place. It recommends a small pilot before adding marketplace integrations, forecasting, or broader ERP features.

The prototype demonstrates an order queue, search and status filters, order creation and validation, stage changes, partial dispatch tracking, payment holds, polishing-lot measurements and reconciliation, and separate return entries.

## Prototype limitations

This is a local front-end demonstration using illustrative sample records. It does not connect to a database or external services, authenticate users, enforce real approval authority, or preserve changes after the page is closed or refreshed. It is not ready for production use.

## Assessment evidence status

The assessment document identifies required real-world evidence that must be supplied by the candidate: the owner or manager audit, process-map and tracking-system photos, consented contact details where requested, and the five-minute walkthrough video. Draft content and the prototype do not substitute for that evidence. Replace provisional marketing text with an anonymized observation from the actual audit, and verify the AI-use note before submission.

Do not claim interviews, observations, consent, or results that did not occur. Keep personal contact details and photographs out of a public Git repository unless the people involved have explicitly consented to that publication.
